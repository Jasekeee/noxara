# NOXARA — product decisions (overnight 2026-11-13/14)

Each decision: options → reference → value / risk / time → choice. Owner feedback from the play-test is the input.

| # | Topic | Options considered | References | Choice | Why |
|---|---|---|---|---|---|
| 1 | In-match menu | (a) Esc/⏸ overlay with Resume / Sound / Controls / Exit to lobby; (b) true pause | Brawl Stars & Fortnite have no real pause in multiplayer; a menu overlay keeps running | **(a) overlay; the match keeps running (it's a fixed-tick sim with bots — pausing offline practice is allowed, chain matches keep ticking); Exit = forfeit (counts as a loss, chain match abandoned → entry rules already handle it)** | No sim change, honest with chain rules; 1 h |
| 2 | Bot names | display name only / fake `name.near` / real account id | Impersonation risk with top-level `.near` names | **Show the REAL sub-account id (e.g. `jinx.royale.br-7e8492.testnet`, mainnet `jinx.noxara.near`), shortened in tight UI (`jinx.noxara…`) with the full id on hover/tap + explorer link. Never invent a top-level name** | Truthful, links to the explorer, zero impersonation risk |
| 3 | Shooting | keep twin-stick only / tap-to-auto-aim / full auto-fire | Brawl Stars: tap = auto-aim at nearest visible enemy, drag = manual aim; light aim assist | **Tap/click-fire auto-aims at the nearest visible enemy in range; drag/mouse keeps manual aim; light assist snaps a manual aim within ±8° to a visible target. Implemented as INPUT (the aim angle that gets recorded), never inside the sim → replays stay bit-exact** | Biggest feel win, no determinism risk; 2 h |
| 4 | Daily check-in | minted login reward / House-paid / none | Axie/STEPN: minted login rewards inflated and got farmed; Clash Royale/Pixels: daily rewards with streaks | **House-paid (never minted), real accounts only, needs ≥1 paid match in the last 48 h (sybil cost = a real entry), 1 per UTC day, streak 1→7 days pays 2,2,3,3,4,4,6 NOX × House multiplier m, capped 100 check-ins/day globally, respects the House floor** | Retention loop without inflation; sybils must pay entries first |
| 5 | Launch NOX? | DEX listing / liquidity pool / in-game only | HACKATHON.md: games track is "judged on the game loop, not the token"; Q-010 testnet projects eligible; launching adds regulatory/price risk | **No launch, no trading, no liquidity during the hackathon. NOX stays an in-game play-money currency. "Launch" stays on the roadmap only, after a real audit and legal review** | Matches the track text and the owner's default; removes the "token treated as investment" risk |
| 6 | Quests | unverifiable social quests with rewards / verifiable in-game quests / social links without rewards | Galxe/Zealy-style social quests get botted; we have no X API | **Daily in-game quests verified on chain from settled matches (play 3 matches, finish top 3, kill the bounty carrier) paying small House-funded NOX to real accounts; social links (follow NEAR / the founder) shown with NO reward** | Only reward what the chain can verify |
| 7 | Challenge a friend | on-chain duel / server-verified shared seed | Clash Royale friendly battles (no stakes) | **Share link with seed + roster; friend plays the same match; results page compares (placement, kills, time alive, bounty); both runs re-verified by the existing replay; no stakes, no tokens** | Viral loop, zero economic risk |
| 8 | Daily tournament | on-chain prize pool / server leaderboard + House-paid prizes | Fortnite daily cups; Brawl Stars challenges | **One seed per UTC day, free, server-verified leaderboard (replay + real-time check); guests listed but earn 0; prizes for real accounts are paid by an owner-run script from the House (play-money), never automatically on chain** | Fast to build, no contract surface |
| 9 | Rookie protection | none / no bounty for rookies / reduced costs early | Brawl Stars matchmaking protects new players; our sim shows most rookies fail | **First 10 matches: no upkeep, never the bounty carrier, entry at the 4-NOX minimum. Re-run the sim and report share returns (median / top 10% / portfolio)** | Gives IPO buyers a fairer start; cheap; sim-checked |

Guardrails kept: no mainnet commands, no public repo, no hosting deploys, no posts. Contract changes ship only after sim + full tests + a fresh security review.
