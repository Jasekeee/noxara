## 5. Решения, которые вам стоит знать
1. **Токен не запускаем.** Трек игр оценивает игру, а не токен (HACKATHON.md); NOX — игровая валюта. Запуск остаётся в планах.
2. **Квесты в соцсетях** — только ссылки без награды: без X API их не проверить, и их будут фармить.
3. **Ежедневные награды** уменьшены до 1–3 NOX: так требовали симулятор и аудит. Иначе казна проседала ниже цели.
4. **Спонсорство в интерфейсе заменено долями**: старая кнопка вызывала бы ошибку контракта.
